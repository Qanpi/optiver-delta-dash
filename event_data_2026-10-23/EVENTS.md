# Optiver Trade-a-thon / live market-making events (research 2026-10-24)

Delta Dash (`delta-dash-eur.optibook.net`) is the platform name for Optiver's **live, in-person
market-making game**: hints on slides reveal an instrument's fair value (e.g. RAIN), you trade it
live on Optibook, first to the target / highest PnL wins. Optiver does not brand it "Delta Dash"
publicly, so it appears under rotating names: "Trade-a-thon", "Tradeathon", "Market Making Game",
"hands-on trading challenge", "Optiver Trading Game", "The Trading Floor".

Our bot (mm/copy/ring strategies) targets THIS format only — not the multi-week Python algo
academies, and not the offline autotrader coding competition (Ready Trader Go / DoCSoc Coding
Challenge).

## NOT the same game (bot does NOT transfer)
- Cambridge / Oxford / Utrecht / Imperial **Trading Academies** — multi-week; write Python algos on

- **Ready Trader Go** / Optiver Coding Challenge with DoCSoc (23 Nov 2026) — offline autotrader coding comp.
- Career fairs (CUES, DoCSoc Exhibition, quant fairs) — no trading game.
